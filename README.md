# 안녕하세요, 백엔드 개발자 신필용입니다.

**비즈니스의 흐름을 이해하고, 데이터의 문제를 해결하는 백엔드 개발자입니다.**

물류 현장에서의 실무 경험을 시작으로 WMS, ERP·MES 프로젝트를 거쳐, 현재는 실제 기업 환경에서 백엔드 시스템을 개발하고 개선하고 있습니다.

이솔테크에서는 제조기업의 영업 시스템을 유지보수하며 Oracle DB와 Baan ERP 간 데이터 흐름을 분석하고, 데이터 정합성 문제를 해결하는 경험을 쌓았습니다.

현재 HLB오션테크에서는 Spring Boot 기반 ERP 시스템을 개발하며, 업무 프로세스 분석부터 데이터베이스 설계, 기능 구현, 기존 시스템 개선까지 수행하고 있습니다.

단순히 기능을 구현하는 것을 넘어 **데이터가 생성되고 변경되는 과정과 비즈니스 규칙을 이해하고, 안정적으로 운영할 수 있는 시스템을 만드는 것**을 중요하게 생각합니다.
